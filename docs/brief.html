    What it does
    
  
    
    
    
      
    Measure
    
      
      
        
    • Exact totals for tagged workloads, kept by the kernel, including processes that exit between samples.
      • 
        
    • Everything else from one bulk snapshot per tick: busy processes every second, idle ones every ten.
      • 
        
    • Memory in units that sum across processes, with separate units for spotting growth.
      • 
        
    • GPU load, VRAM, frequency, throttling, battery and connections, each marked full, partial or unavailable.
      • 
      
    
    
    
    
    
      
    Attribute
    
      
      
        
    • submeter run --as NAME -- COMMAND tags a whole process tree at launch.
      • 
        
    • Rules claim everything else by executable, command line, parent or folder.
      • 
        
    • Every workload shows whether the kernel or polling measured it.
      • 
        
    • Unattributed, System, Restricted and Submeter itself are always shown, and the parts must sum to the whole.
      • 
      
    
    
    
    
    
      
    Remember
    
      
      
        
    • Three lifetimes in three kinds of file: 48 hours of full detail, 30 days by the minute, hourly history kept.
      • 
        
    • Retention is a file delete, under a 2 GB cap that is enforced exactly.
      • 
        
    • Sessions and tagged runs are summarised when they end, so their cost stays exact for good.
      • 
        
    • Every change of settings, rules or hardware starts a new epoch, marked on the charts.
      • 
      
    
    
    
    
    
      
    Explain
    
      
      
        
    • A bottleneck verdict with confidence and evidence, or Inconclusive.
      • 
        
    • Leak detection that waits for growth with no plateau.
      • 
        
    • Baselines learned separately for idle and active use.
      • 
        
    • Session diffs ranked by size of change.
      • 
      
    
    
    
    
    
      
    Show
    
      
      
        
    • Live dashboard, history explorer, findings feed and session compare.
      • 
        
    • A CLI with JSON output on every command.
      • 
        
    • Self-contained HTML reports and alerts with cooldowns.
      • 
        
    • A read-only MCP server, so an agent can ask what it is costing.
      • 
      
    
    
    
    
    
      
    Protect
    
      
      
        
    • Observe only. No setting lets version 1 act on a process.
      • 
        
    • Command lines are scrubbed of secrets before they are stored.
      • 
        
    • The local API needs a token and refuses requests from web pages.
      • 
        
    • Runs as the signed-in user and never asks for administrator rights.
      • 
        
    • Nothing leaves the machine.
      •

    What is kept, where, and for how long

    What every bucket records
    
  
    
    
      
      
    • For counters such as CPU seconds, bytes read and written, and processes started: the sum. A total over any period is then an exact sum of sums.
      • 
      
    • For gauges such as memory, process count and frequency: minimum, maximum, time-weighted mean and last value.
      • 
      
    • For CPU cores in use and memory: a small histogram. A percentile over any period comes from merged bins, never from averaging percentiles.
      • 
      
    • Covered seconds and sample count, so a gap is never read as zero use.
      • 
      
    • Active seconds, so idle and busy periods can be compared separately.
      • 
      
    • The machine's capacity at the time and an epoch number, both explained below.
      • 
    
    
  
    

  
    Which data answers which question
    
  
  
    
    
      
      
    • A question is answered from the finest tier that covers its whole window, and every answer states the tier and resolution it came from.
      • 
      
    • Charts draw the minimum-to-maximum envelope, so a spike survives in coarser tiers.
      • 
      
    • A session or tagged run is summarised when it ends, so its cost stays exact after its raw data is gone.
      • 
      
    • Each hour keeps the top ten executables per workload by CPU time and by peak memory, for a year. That answers "what inside the browser grew last week" without keeping every process.
      •

    When two periods can be compared
    
  
    
    
      
      
    • An epoch is a stretch of time in which the sampling intervals, the rules file, each provider's status, the hardware and the Submeter version all stayed the same. Any change starts a new epoch and is marked on every chart.
      • 
      
    • Sums compare freely across epochs. Maxima and percentiles depend on the sampling interval, so a comparison that crosses an interval change is flagged.
      • 
      
    • A rules change moves processes between workloads. Stored history is not rewritten. The boundary is marked.
      • 
      
    • Percentages use the capacity recorded in each bucket, so new hardware does not distort old data.
      • 
      
    • Buckets with less than half their time covered are left out of baselines and trends.
      • 
      
    • Days and weeks are worked out in your time zone when you ask, from buckets stored in UTC. A day of 23 or 25 hours is compared per hour.
      • 
      
    • A workload name is stable and reused across runs. A label marks one run. Time series are kept per name and totals per run, so a new label never starts a new series.
      •

    File activity of the processes being watched
    
  
    Submeter records bytes read and written, and handle counts, per process, with disk latency and queue length for the system. It does not record which files a process touches. That needs the deep tracing left out of version 1, and it is listed under Known limits.

    How configuration behaves
    
  
    
    
      
      
    • Precedence is command-line flag, then environment variable, then file, then built-in default.
      • 
      
    • submeter config show --effective prints every value and where it came from.
      • 
      
    • submeter config check validates a file without applying it.
      • 
      
    • Out-of-range values are refused with the allowed range in the message. They are never silently clamped.
      • 
      
    • Any change to sampling, rules or providers starts a new epoch, which is marked on every chart.
      • 
      
    • Each machine can carry a named profile, so the desktop and the laptop share one file.
      • 
    
    
  
    

  
    Fixed on purpose
    
  
    
    
      
      
    • Observe-only. No setting lets version 1 act on a process.
      • 
      
    • The collector and server run as the signed-in user. They never ask for administrator rights.
      • 
      
    • Nothing is sent off the machine. There is no webhook, upload or update check.
      • 
      
    • The API binds to loopback and always requires a token.
      • 
      
    • The MCP server never returns command lines, whatever the redaction mode.
      • 
      
    • Unavailable metrics stay unavailable. There is no option to fill gaps with estimates.
      •

    Sample rules.toml

    Terms used here
    
  
    
    
    Workload
    A named group of processes whose cost is reported together, such as one agent run or the browser.
    
    
    Kernel accounting
    Totals the operating system keeps for a group of processes, including those that have exited.
    
    
    Job Object
    The Windows mechanism for grouping processes and accounting for them together.
    
    
    cgroup
    The Linux equivalent: a control group with its own usage counters.
    
    
    Hot and cold sets
    Recently active processes, sampled often, and idle ones, sampled rarely.
    
    
    USS
    Unique set size. Memory that belongs to one process alone and would be freed if it exited.
    
    
    PSS
    Proportional set size. USS plus a fair share of every shared page. Linux only.
    
    
    Private bytes
    Memory a Windows process has committed for itself, whether or not it is in RAM.
    
    
    Working set
    The part of a process's memory currently in RAM. Windows trims it under pressure.
    
    
    Commit
    Memory the system has promised to processes. Allocations fail as it nears the limit.
    
    
    PSI
    Pressure stall information. Linux's measure of time lost waiting for CPU, memory or I/O.
    
    
    MAD
    Median absolute deviation. A measure of spread that outliers barely move.

    """Durations, sizes, rates and percentages, written the way a person writes them.

Settings say "250ms", "48h", "2GB", "50MB/h" and "1%". Inside the program
everything is seconds, bytes, bytes per second and fractions. This module is
the only place that converts between the two, so every complaint about a
malformed value comes from here and reads the same way.
"""

from __future__ import annotations

import math
import re
from collections.abc import Callable
from typing import Annotated, Final

from pydantic import BeforeValidator

FOREVER: Final[float] = math.inf

_DURATION_UNITS: Final[dict[str, float]] = {
    "ms": 0.001,
    "s": 1.0,
    "m": 60.0,
    "h": 3600.0,
    "d": 86400.0,
    "w": 604800.0,
    "y": 31536000.0,
}
_SIZE_UNITS: Final[dict[str, int]] = {
    "": 1,
    "k": 1024,
    "m": 1024**2,
    "g": 1024**3,
    "t": 1024**4,
}
_NUMBER: Final = r"(\d+(?:\.\d+)?)"
_DURATION_RE: Final = re.compile(rf"^\s*{_NUMBER}\s*(ms|s|m|h|d|w|y)\s*$")
_SIZE_RE: Final = re.compile(rf"^\s*{_NUMBER}\s*([kmgt]?)i?b\s*$", re.IGNORECASE)
_PERCENT_RE: Final = re.compile(rf"^\s*{_NUMBER}\s*%\s*$")


def parse_duration(value: object) -> float:
    """Return seconds for "250ms", "5m", "48h", "forever" or a plain number of seconds."""
    if isinstance(value, int | float) and not isinstance(value, bool):
        return float(value)
    if isinstance(value, str):
        if value.strip().lower() == "forever":
            return FOREVER
        match = _DURATION_RE.match(value)
        if match:
            return float(match.group(1)) * _DURATION_UNITS[match.group(2)]
    raise ValueError(f"not a duration: {value!r} (write it like '250ms', '5m' or '48h')")


def parse_size(value: object) -> int:
    """Return bytes for "8MB" or "2GB". Units are binary, so 1 GB is 1024**3 bytes."""
    if isinstance(value, int) and not isinstance(value, bool):
        return value
    if isinstance(value, str):
        match = _SIZE_RE.match(value)
        if match:
            return round(float(match.group(1)) * _SIZE_UNITS[match.group(2).lower()])
    raise ValueError(f"not a size: {value!r} (write it like '8MB' or '2GB')")


def parse_percent(value: object) -> float:
    """Return a fraction for "1%". A bare number is taken as a fraction already."""
    if isinstance(value, int | float) and not isinstance(value, bool):
        return float(value)
    if isinstance(value, str):
        match = _PERCENT_RE.match(value)
        if match:
            return float(match.group(1)) / 100.0
    raise ValueError(f"not a percentage: {value!r} (write it like '1%')")


def parse_rate(value: object) -> float:
    """Return bytes per second for "50MB/h". A bare number is bytes per second."""
    if isinstance(value, int | float) and not isinstance(value, bool):
        return float(value)
    if isinstance(value, str) and "/" in value:
        size, _, per = value.partition("/")
        try:
            return parse_size(size) / parse_duration("1" + per.strip())
        except ValueError:
            pass
    raise ValueError(f"not a rate: {value!r} (write it like '50MB/h')")


def format_duration(seconds: float) -> str:
    """Write seconds back in the largest unit that divides them evenly."""
    if math.isinf(seconds):
        return "forever"
    if 0 < seconds < 1:
        return f"{round(seconds * 1000)}ms"
    for unit in ("d", "h", "m", "s"):
        size = _DURATION_UNITS[unit]
        if seconds >= size and math.isclose(seconds / size, round(seconds / size)):
            return f"{round(seconds / size)}{unit}"
    return f"{seconds:g}s"


def format_size(size: float) -> str:
    """Write bytes with a binary unit and at most two decimals."""
    for prefix in ("t", "g", "m", "k"):
        unit = _SIZE_UNITS[prefix]
        if abs(size) >= unit:
            return f"{size / unit:.2f}".rstrip("0").rstrip(".") + f" {prefix.upper()}B"
    return f"{round(size)} B"


def duration_range(low: str, high: str) -> Callable[[float], float]:
    """Build a validator that refuses durations outside low..high and says so."""
    lowest, highest = parse_duration(low), parse_duration(high)

    def check(value: float) -> float:

    """A fixed-bin histogram that can be merged, so percentiles survive rollups.

A percentile of percentiles is not a percentile. Keeping a small histogram in
every bucket fixes that: merging two histograms is adding their bins, and a
percentile over any period is read from the merged bins.

Bins are spaced geometrically between `low` and `high`, with one bin below and
one above. A reported percentile lands in the right bin, so it is within one
bin of the true value: a factor of about 1.17 with the scales defined here.
"""

from __future__ import annotations

import math
from collections.abc import Sequence
from dataclasses import dataclass
from typing import Final


@dataclass(frozen=True, slots=True)
class Scale:
    """Where the bin edges are. Two histograms can be merged only on the same scale."""

    low: float
    high: float
    bins: int = 64

    @property
    def size(self) -> int:
        return self.bins + 2

    def index(self, value: float) -> int:
        if value < self.low:
            return 0
        if value >= self.high:
            return self.bins + 1
        position = math.log(value / self.low) / math.log(self.high / self.low)
        return 1 + min(self.bins - 1, int(position * self.bins))

    def edges(self, index: int) -> tuple[float, float]:
        """Lower and upper edge of a bin. The first bin starts at zero."""
        if index <= 0:
            return 0.0, self.low
        if index > self.bins:
            return self.high, self.high
        ratio = self.high / self.low
        return (
            self.low * math.pow(ratio, (index - 1) / self.bins),
            self.low * math.pow(ratio, index / self.bins),
        )


CORES: Final = Scale(low=0.01, high=256.0)
MEMORY: Final = Scale(low=16 * 1024**2, high=256 * 1024**3)


def empty(scale: Scale) -> list[float]:
    return [0.0] * scale.size


def add(counts: list[float], scale: Scale, value: float, weight: float = 1.0) -> None:
    """Add one observation in place. Weight is usually the seconds it was observed for."""
    counts[scale.index(value)] += weight


def merge(first: Sequence[float], second: Sequence[float]) -> tuple[float, ...]:
    """Add two histograms bin by bin. They must share a scale; only the bin count is checked."""
    if len(first) != len(second):
        raise ValueError("histograms with different bin counts cannot be merged")
    return tuple(a + b for a, b in zip(first, second, strict=True))


def percentile(counts: Sequence[float], scale: Scale, q: float) -> float | None:
    """Return the q-th percentile (q from 0 to 100), or None for an empty histogram."""
    if len(counts) != scale.size:
        raise ValueError("histogram does not match the scale")
    total = sum(counts)
    if total <= 0:
        return None
    target = total * min(max(q, 0.0), 100.0) / 100.0
    running = 0.0
    for index, count in enumerate(counts):
        if count <= 0:
            continue
        if running + count >= target:
            lower, upper = scale.edges(index)
            inside = (target - running) / count
            if lower <= 0 or upper == lower:
                return lower + (upper - lower) * inside
            return lower * math.pow(upper / lower, inside)
        running += count
    return scale.high

Command lines carry API keys, tokens and passwords. This module is applied on
the way into the store, so no later bug can expose what was never written.

It errs towards hiding too much. An argument that follows a secret-looking
flag is hidden, values of secret-looking NAME=value pairs are hidden, known
token shapes are hidden wherever they appear, and any long opaque string of
letters and digits is hidden. The executable itself is always kept.
"""

from __future__ import annotations

import re
from collections.abc import Sequence
from typing import Final, Literal

REDACTED: Final = "[redacted]"
Mode = Literal["scrub", "exe_only"]

_SECRET_NAME: Final = re.compile(
    r"pass(word|wd)?|pwd|secret|token(?!s)|credential|authorization|bearer"
    r"|(api|access|secret|private)[-_]?key",
    re.IGNORECASE,
)
_SECRET_SHAPES: Final = (
    re.compile(r"\bsk-[A-Za-z0-9_-]{16,}"),
    re.compile(r"\bgh[pousr]_[A-Za-z0-9]{20,}"),
    re.compile(r"\bxox[abprs]-[A-Za-z0-9-]{10,}"),
    re.compile(r"\bAKIA[0-9A-Z]{16}\b"),
    re.compile(r"\beyJ[A-Za-z0-9_-]{8,}\.[A-Za-z0-9_-]{8,}\.[A-Za-z0-9_-]{8,}"),
)
_URL_PASSWORD: Final = re.compile(
    r"(?P<head>[a-z][a-z0-9+.-]*://[^/\s:@]+):[^@\s/]+@", re.IGNORECASE

_OPAQUE: Final = re.compile(r"^[A-Za-z0-9+/_=-]{32,}$")


def _looks_opaque(text: str) -> bool:
    return (
        bool(_OPAQUE.match(text))
        and any(c.isdigit() for c in text)
        and any(c.isalpha() for c in text)
    )


def redact_text(text: str, extra: Sequence[re.Pattern[str]] = ()) -> str:
    """Hide known secret shapes and URL passwords inside free text, such as a log line."""
    text = _URL_PASSWORD.sub(rf"\g<head>:{REDACTED}@", text)
    for pattern in (*_SECRET_SHAPES, *extra):

    return text

class PsutilProvider:
    name = "process.psutil"

    def __init__(self, *, read_cwd: bool = False) -> None:
        self._read_cwd = read_cwd
        self._seen = 0
        self._restricted = 0

    def capability(self) -> Capability:
        if self._restricted:
            note = f"{self._restricted} of {self._seen} processes not fully readable"
            return Capability(name=self.name, status=Availability.PARTIAL, note=note)
        return Capability(name=self.name, status=Availability.FULL)

    def snapshot(self) -> Snapshot:
        taken_at, monotonic = time.time(), time.monotonic()
        processes = [c for c in map(self._read, psutil.process_iter()) if c is not None]
        self._seen = len(processes)
        self._restricted = sum(1 for c in processes if c.restricted)
        return Snapshot(
            taken_at=taken_at,
            monotonic=monotonic,
            processes=tuple(processes),
            system=self._system(),
        )

    def _read(self, process: psutil.Process) -> ProcessCounters | None:
        try:
            with process.oneshot():
                key = ProcessKey(pid=process.pid, started=process.create_time())
                restricted = False
                try:
                    times = process.cpu_times()
                    memory = process.memory_info()
                    cpu_s = times.user + times.system
                    memory_bytes = int(getattr(memory, "private", memory.rss))
                    threads = process.num_threads()
                except psutil.AccessDenied:
                    cpu_s, memory_bytes, threads, restricted = 0.0, 0, 0, True
                cmdline: tuple[str, ...] | None = None
                try:
                    cmdline = tuple(process.cmdline())
                except psutil.AccessDenied:
                    restricted = True
                read_bytes: int | None = None
                write_bytes: int | None = None
                io_counters = getattr(process, "io_counters", None)  # psutil has none on macOS
                if io_counters is not None:
                    try:
                        io = io_counters()
                        read_bytes, write_bytes = int(io.read_bytes), int(io.write_bytes)
                    except psutil.AccessDenied:
                        restricted = True
                    except NotImplementedError:
                        pass
                cwd: str | None = None
                if self._read_cwd:
                    try:
                        cwd = process.cwd()
                    except psutil.AccessDenied:
                        restricted = True
                return ProcessCounters(
                    key=key,
                    parent_pid=process.ppid(),
                    exe=process.name(),
                    cmdline=cmdline,
                    cwd=cwd,
                    cpu_s=cpu_s,
                    io_read_bytes=read_bytes,
                    io_write_bytes=write_bytes,
                    memory_bytes=memory_bytes,
                    threads=threads,
                    restricted=restricted,
                )
        except (psutil.NoSuchProcess, psutil.ZombieProcess):
            return None
        except psutil.AccessDenied:
            return ProcessCounters(
                key=ProcessKey(pid=process.pid, started=0.0),
                cpu_s=0.0,
                memory_bytes=0,
                restricted=True,

            cpu_busy_s=busy,
            memory_total_bytes=memory.total,
            memory_available_bytes=memory.available,
        )

    """Turn cumulative counters into what happened during each interval.

Providers hand over running totals. The sampler keeps the previous snapshot,
subtracts, and returns one batch per interval. Because it works from totals,
a change of cadence never loses or invents CPU time: a longer interval simply
carries a larger delta.

Three cases need care, and each is handled here and nowhere else:
- a process seen for the first time, whose whole CPU time belongs to this
  interval if it was born during it, and to no interval if it is older;
- a pid that has been reused, which is a different process because identity
  is pid plus start time;
- a sleep or stall, where the interval was not observed and must be recorded
  as a gap instead of one enormous sample.
"""

from __future__ import annotations

from submeter.core.models import (
    ProcessCounters,
    ProcessKey,
    ProcessSample,
    SampleBatch,
    Snapshot,
)


def _delta(now: int | None, before: int | None) -> int | None:
    if now is None or before is None:
        return None
    return max(0, now - before)


def _zero(value: int | None) -> int | None:
    return None if value is None else 0


class Sampler:
    def __init__(self, *, gap_after_s: float = 30.0, suspend_slack_s: float = 2.0) -> None:
        self._gap_after_s = gap_after_s
        self._suspend_slack_s = suspend_slack_s
        self._previous: Snapshot | None = None
        self._known: dict[ProcessKey, ProcessCounters] = {}

    def ingest(self, snapshot: Snapshot) -> SampleBatch | None:
        """Return the batch for the interval ending here. The first call returns None."""
        previous, known = self._previous, self._known
        self._previous = snapshot
        self._known = {process.key: process for process in snapshot.processes}
        if previous is None:
            return None

        elapsed = snapshot.monotonic - previous.monotonic
        wall = snapshot.taken_at - previous.taken_at
        gap = elapsed <= 0 or elapsed > self._gap_after_s or wall - elapsed > self._suspend_slack_s
        busy = sum(snapshot.system.cpu_busy_s) - sum(previous.system.cpu_busy_s)
        return SampleBatch(
            taken_at=snapshot.taken_at,
            interval_s=max(elapsed, wall) if gap else elapsed,
            gap=gap,
            processes=tuple(
                self._sample(process, known.get(process.key), previous.taken_at, gap)
                for process in snapshot.processes
            ),
            exited=tuple(key for key in known if key not in self._known),
            logical_cores=snapshot.system.logical_cores,
            cpu_busy_s=0.0 if gap else max(0.0, busy),
            memory_available_bytes=snapshot.system.memory_available_bytes,
        )

    @staticmethod
    def _sample(
        now: ProcessCounters,
        before: ProcessCounters | None,
        previous_at: float,
        gap: bool,
    ) -> ProcessSample:
        if gap:
            cpu_s, read, write = 0.0, _zero(now.io_read_bytes), _zero(now.io_write_bytes)
        elif before is not None:
            cpu_s = max(0.0, now.cpu_s - before.cpu_s)
            read = _delta(now.io_read_bytes, before.io_read_bytes)
            write = _delta(now.io_write_bytes, before.io_write_bytes)
        elif now.key.started >= previous_at - 1.0:
            cpu_s, read, write = now.cpu_s, now.io_read_bytes, now.io_write_bytes
        else:
            cpu_s, read, write = 0.0, _zero(now.io_read_bytes), _zero(now.io_write_bytes)
        return ProcessSample(
            key=now.key,
            parent_pid=now.parent_pid,
            exe=now.exe,
            cmdline=now.cmdline,
            cwd=now.cwd,
            cpu_s=cpu_s,
            io_read_bytes=read,
            io_write_bytes=write,
            memory_bytes=now.memory_bytes,
            threads=now.threads,
            first_seen=before is None,
            restricted=now.restricted,
        )


def hot_keys(batch: SampleBatch, *, cpu_threshold: float) -> frozenset[ProcessKey]:
    """Processes worth sampling at the active interval: new ones, and any above the threshold."""
    if batch.interval_s <= 0:
        return frozenset()
    return frozenset(
        sample.key
        for sample in batch.processes
        if sample.first_seen or sample.cpu_s / batch.interval_s >= cpu_threshold

class Rule(Record):
    """One entry of rules.toml. Every condition that is given must hold."""

    workload: str
    priority: int = 0
    exe: tuple[str, ...] = ()
    cmdline: str | None = None
    cwd: str | None = None
    parent: tuple[str, ...] = ()
    include_children: bool = False
    note: str = ""

    @model_validator(mode="after")
    def _usable(self) -> Rule:
        if not (self.exe or self.cmdline or self.cwd or self.parent):
            raise ValueError("a rule needs at least one of exe, cmdline, cwd or parent")
        if self.cmdline is not None:
            try:
                re.compile(self.cmdline)
            except re.error as error:
                raise ValueError(f"cmdline is not a valid pattern: {error}") from error
        return self

    def matches(self, process: ProcessSample, parent: ProcessSample | None = None) -> bool:
        """`parent` is the process that started this one, when it is known and still running."""
        if self.exe and _base_name(process.exe) not in {name.lower() for name in self.exe}:
            return False
        if self.parent and (
            parent is None or _base_name(parent.exe) not in {name.lower() for name in self.parent}
        ):
            return False
        if self.cmdline is not None and (
            process.cmdline is None or not _pattern(self.cmdline).search(" ".join(process.cmdline))
        ):
            return False
        return self.cwd is None or (
            process.cwd is not None and fnmatch.fnmatchcase(_folder(process.cwd), _folder(self.cwd))
        )


class RuleSet(Record):

    @classmethod
    def load(cls, path: Path) -> RuleSet:

            return cls.model_validate(tomllib.load(handle))

    @property
    def needs_cwd(self) -> bool:
        """True when some rule matches on the working folder, which costs extra to read."""
        return any(rule.cwd is not None for rule in self.rule)

    def ordered(self) -> tuple[Rule, ...]:
        """Highest priority first. Order in the file breaks ties."""
        ranked = sorted(enumerate(self.rule), key=lambda pair: (-pair[1].priority, pair[0]))

class Attributor:
    def __init__(
        self,
        rules: RuleSet,
        *,
        inherit_from_parent: bool = True,
        self_pid: int | None = None,
    ) -> None:
        self._rules = rules.ordered()
        self._inherit = inherit_from_parent
        self._self_pid = self_pid

    def assign(
        self,
        processes: Sequence[ProcessSample],
        tagged: Mapping[ProcessKey, str] | None = None,
    ) -> dict[ProcessKey, Attribution]:
        """Give every process exactly one workload, with the reason it got it."""
        groups = tagged or {}
        by_pid = {process.key.pid: process for process in processes}
        resolved: dict[ProcessKey, Attribution] = {}

        def resolve(process: ProcessSample, trail: frozenset[int]) -> Attribution:
            known = resolved.get(process.key)
            if known is not None:
                return known
            parent = by_pid.get(process.parent_pid) if process.parent_pid is not None else None
            if parent is not None and (
                parent.key.pid == process.key.pid or parent.key.started > process.key.started
            ):
                parent = None  # a reused pid, not the process that started this one
            result = self._direct(process, groups, parent)
            if result is None and parent is not None and parent.key.pid not in trail:
                above = resolve(parent, trail | {process.key.pid})
                if above.inheritable:
                    reason = f"inherited from pid {parent.key.pid}"
                    result = Attribution(workload=above.workload, reason=reason, inheritable=True)
            if result is None:
                bucket = RESTRICTED if process.restricted else UNATTRIBUTED
                result = Attribution(workload=bucket, reason="no rule matched")
            resolved[process.key] = result
            return result

        for process in processes:
            resolve(process, frozenset())
        return resolved

    def _direct(
        self,
        process: ProcessSample,
        groups: Mapping[ProcessKey, str],
        parent: ProcessSample | None,
    ) -> Attribution | None:
        group = groups.get(process.key)
        if group is not None:
            return Attribution(workload=group, reason="kernel group", inheritable=True)
        if process.key.pid == self._self_pid:
            return Attribution(workload=SELF, reason="submeter itself", inheritable=True)
        for rule in self._rules:
            if rule.matches(process, parent):
                return Attribution(
                    workload=rule.workload,
                    reason=f"rule for {rule.workload}",
                    inheritable=self._inherit or rule.include_children,
                )
        return None

    io_read_bytes: int = 0
    io_write_bytes: int = 0
    processes: int = 0
    started: int = 0


def aggregate(
    batch: SampleBatch,
    assignment: Mapping[ProcessKey, Attribution],
    *,
    kernel_workloads: Collection[str] = (),
) -> tuple[WorkloadSample, ...]:
    """Total a batch per workload, largest CPU user first."""
    totals: dict[str, _Total] = {}
    for process in batch.processes:
        total = totals.setdefault(assignment[process.key].workload, _Total())
        total.cpu_s += process.cpu_s
        total.memory_bytes += process.memory_bytes
        total.io_read_bytes += process.io_read_bytes or 0
        total.io_write_bytes += process.io_write_bytes or 0
        total.processes += 1
        total.started += process.first_seen

        if workload in kernel_workloads:
            return AccountingSource.KERNEL
        return AccountingSource.PARTIAL if workload == RESTRICTED else AccountingSource.POLLED

    samples = (
        WorkloadSample(
            taken_at=batch.taken_at,
            interval_s=batch.interval_s,
            workload=workload,

            cpu_s=total.cpu_s,
            memory_bytes=total.memory_bytes,
            io_read_bytes=total.io_read_bytes,
            io_write_bytes=total.io_write_bytes,
            processes=total.processes,
            started=total.started,
        )
        for workload, total in totals.items()
    )
    return tuple(sorted(samples, key=lambda sample: -sample.cpu_s))

def _try_lock(fd: int) -> bool:
    """Take an exclusive lock on an open file without waiting. False when another holder has it.

    Windows locks one byte at the start of the file, which may lie past the end of an empty file.
    The lock belongs to the handle, so the file itself is never written: other programs could
    not read a locked byte, and nothing here depends on its contents.
    """
    try:
        if sys.platform == "win32":
            import msvcrt

            os.lseek(fd, 0, os.SEEK_SET)
            msvcrt.locking(fd, msvcrt.LK_NBLCK, 1)
        else:
            import fcntl

            fcntl.flock(fd, fcntl.LOCK_EX | fcntl.LOCK_NB)
    except OSError:
        return False
    return True


def _unlock(fd: int) -> None:
    """Give the lock back. Closing the file would also do it; this keeps the order explicit."""
    try:
        if sys.platform == "win32":
            import msvcrt

            os.lseek(fd, 0, os.SEEK_SET)
            msvcrt.locking(fd, msvcrt.LK_UNLCK, 1)
        else:
            import fcntl

            fcntl.flock(fd, fcntl.LOCK_UN)
    except OSError:
        pass


class InstanceLock:
    """An exclusive lock held for as long as a program runs, so two copies cannot.

    The lock file is only ever locked, never written. The holder's pid goes in a file beside it,
    NAME.pid, which anyone may read. The operating system frees the lock if the holder dies.

    The POSIX path is exercised by the tests. The Windows path is exercised against a stand-in
    for msvcrt, which checks the calls made but not how Windows answers them. It still needs
    running on Windows: see docs/reference/windows-priorities.md.
    """

    def __init__(self, path: Path) -> None:
        self._path = path
        self._fd: int | None = None

    @property
    def pid_file(self) -> Path:
        return self._path.with_suffix(".pid")

    def acquire(self) -> bool:
        self._path.parent.mkdir(parents=True, exist_ok=True)
        try:
            fd = os.open(self._path, os.O_RDWR | os.O_CREAT, 0o600)
        except OSError:
            return False  # on Windows another holder can make even opening fail
        if not _try_lock(fd):
            os.close(fd)
            return False
        self._fd = fd
        with contextlib.suppress(OSError):  # the pid is a convenience; the lock is what matters
            self.pid_file.write_text(str(os.getpid()), encoding="ascii")
        return True

    def holder(self) -> int | None:
        """The pid recorded by whoever last took the lock, if it can be read."""
        try:
            return int(self.pid_file.read_text(encoding="ascii").strip())
        except (OSError, ValueError):
            return None

    def release(self) -> None:
        if self._fd is None:
            return
        with contextlib.suppress(OSError):
            self.pid_file.unlink()
        _unlock(self._fd)
        os.close(self._fd)
        self._fd = None

    def __enter__(self) -> InstanceLock:
        if not self.acquire():
            raise RuntimeError(f"another copy is already running (lock: {self._path})")
        return self

    def __exit__(
        self,
        kind: type[BaseException] | None,
        error: BaseException | None,
        trace: TracebackType | None,
    ) -> None:
        self.release()

class RawFile:
    def __init__(
        self,
        path: Path,
        *,
        cpu_points: float = 0.5,
        memory_step: int = 8 * 1024**2,
        redaction: Mode = "scrub",
    ) -> None:
        path.parent.mkdir(parents=True, exist_ok=True)
        self.path = path
        self._db = sqlite3.connect(path)
        self._db.execute("PRAGMA journal_mode=WAL")
        self._db.execute("PRAGMA synchronous=NORMAL")
        self._db.execute("PRAGMA journal_size_limit=67108864")
        self._db.executescript(_SCHEMA)
        with self._db:
            self._db.execute(
                "INSERT OR IGNORE INTO meta VALUES ('schema_version', ?)", (str(SCHEMA_VERSION),)
            )
        self._cpu_share = cpu_points / 100.0
        self._memory_step = memory_step
        self._redaction: Mode = redaction
        self._pending: dict[ProcessKey, float] = {}
        self._waited: dict[ProcessKey, float] = {}
        self._memory: dict[ProcessKey, int] = {}
        self._threads: dict[ProcessKey, int] = {}

    def write(
        self,
        batch: SampleBatch,
        workloads: Sequence[WorkloadSample],
        workload_of: Mapping[ProcessKey, str],
        *,
        keyframe: bool = False,
    ) -> int:
        """Store one batch in one transaction. Returns how many process rows were written."""
        written = 0
        full = keyframe or batch.gap
        with self._db:
            if batch.gap:
                start = batch.taken_at - batch.interval_s
                self._db.execute(
                    "INSERT INTO gap VALUES (?, ?, ?)", (start, batch.taken_at, "not observed")
                )
            self._db.execute(
                "INSERT OR REPLACE INTO system_raw VALUES (?, ?, ?, ?, ?)",
                (
                    batch.taken_at,
                    batch.interval_s,
                    batch.logical_cores,
                    batch.cpu_busy_s,
                    batch.memory_available_bytes,
                ),
            )
            self._db.executemany(
                "INSERT OR REPLACE INTO workload_raw VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)",
                [
                    (
                        w.taken_at,
                        w.workload,
                        w.source.value,
                        w.interval_s,
                        w.cpu_s,
                        w.memory_bytes,
                        w.io_read_bytes,
                        w.io_write_bytes,
                        w.processes,
                        w.started,
                    )
                    for w in workloads
                ],
            )
            for sample in batch.processes:
                key = sample.key
                if key not in self._memory:
                    self._register(sample, workload_of.get(key, "unattributed"), batch.taken_at)
                pending = self._pending.get(key, 0.0) + sample.cpu_s
                waited = self._waited.get(key, 0.0) + batch.interval_s
                last = self._memory.get(key)
                moved = last is None or abs(sample.memory_bytes - last) >= self._memory_step
                if full or moved or pending >= self._cpu_share * waited:
                    self._row(
                        batch.taken_at, key, pending, sample.memory_bytes, sample.threads, full
                    )
                    self._memory[key] = sample.memory_bytes
                    pending, waited = 0.0, 0.0
                    written += 1
                self._pending[key], self._waited[key] = pending, waited
                self._threads[key] = sample.threads
            for key in batch.exited:
                written += self._finish(batch.taken_at, key)
        return written

    def _register(self, sample: ProcessSample, workload: str, seen_at: float) -> None:
        command_id: int | None = None
        if sample.cmdline:
            text = " ".join(redact_cmdline(sample.cmdline, mode=self._redaction))
            self._db.execute("INSERT OR IGNORE INTO command (text) VALUES (?)", (text,))
            row = self._db.execute("SELECT id FROM command WHERE text = ?", (text,)).fetchone()
            command_id = int(row[0])
        self._db.execute(
            "INSERT OR IGNORE INTO process VALUES (?, ?, ?, ?, ?, ?, ?)",
            (
                sample.key.pid,
                sample.key.started,
                sample.parent_pid,
                sample.exe,
                command_id,
                workload,
                seen_at,
            ),
        )

    def _row(
        self, ts: float, key: ProcessKey, cpu_s: float, memory: int, threads: int, full: bool
    ) -> None:
        self._db.execute(
            "INSERT OR REPLACE INTO process_raw VALUES (?, ?, ?, ?, ?, ?, ?)",
            (ts, key.pid, key.started, cpu_s, memory, threads, int(full)),
        )

    def _finish(self, ts: float, key: ProcessKey) -> int:
        """Write whatever CPU a process still had pending, then forget it."""
        pending = self._pending.pop(key, 0.0)
        self._waited.pop(key, None)
        memory = self._memory.pop(key, 0)
        threads = self._threads.pop(key, 0)
        if pending <= 0:
            return 0
        self._row(ts, key, pending, memory, threads, False)
        return 1

    def record_event(self, ts: float, kind: str, detail: str) -> None:
        """Note something that starts a new epoch: an interval change, a provider falling back."""
        with self._db:
            self._db.execute("INSERT INTO event VALUES (?, ?, ?)", (ts, kind, detail))

    def workload_samples(self, start: float, end: float) -> list[WorkloadSample]:
        rows = self._db.execute(
            "SELECT ts, interval_s, workload, source, cpu_s, memory_bytes, io_read_bytes,"
            " io_write_bytes, processes, started FROM workload_raw"
            " WHERE ts > ? AND ts <= ? ORDER BY ts, workload",
            (start, end),
        ).fetchall()
        return [

                taken_at=row[0],
                interval_s=row[1],
                workload=row[2],
                source=AccountingSource(row[3]),
                cpu_s=row[4],
                memory_bytes=row[5],
                io_read_bytes=row[6],
                io_write_bytes=row[7],
                processes=row[8],
                started=row[9],
            )
            for row in rows
        ]

    def process_cpu_total(self) -> float:
        row = self._db.execute("SELECT COALESCE(SUM(cpu_s), 0) FROM process_raw").fetchone()
        return float(row[0])

    def count(self, table: str) -> int:
        if table not in {"command", "event", "gap", "process", "process_raw", "workload_raw"}:
            raise ValueError(f"unknown table: {table}")

    """Fold samples into buckets, and buckets into larger buckets, without losing the totals.

A bucket keeps sums for counters, the minimum, maximum, time-weighted mean and
last value for gauges, a time-weighted histogram for cores in use and for
memory, and how many seconds it really covers. That is enough to merge any
number of buckets exactly: a week's CPU-hours is a sum of sums, and a week's
95th percentile is read from merged bins.

The same functions build minute buckets from raw samples and hourly buckets
from minute buckets. Nothing here touches a file.
"""

from __future__ import annotations

import math
from collections.abc import Iterable, Sequence

from submeter.core import histogram
from submeter.core.models import Bucket, WorkloadSample


def bucket_start(timestamp: float, width_s: float) -> float:
    return math.floor(timestamp / width_s) * width_s


class SeriesAccumulator:
    """Collects the samples of one series that fall inside one bucket."""

    def __init__(
        self,
        *,
        series: str,
        start: float,
        width_s: float,
        logical_cores: int,
        epoch: int = 0,
        active_share: float = 0.005,
    ) -> None:
        self._series, self._start, self._width_s = series, start, width_s
        self._logical_cores, self._epoch, self._active_share = logical_cores, epoch, active_share
        self._covered_s = self._active_s = self._cpu_s = self._memory_weighted = 0.0
        self._samples = self._read = self._write = self._started = self._processes_max = 0
        self._memory_min: int | None = None
        self._memory_max = self._memory_last = 0
        self._cores = histogram.empty(histogram.CORES)
        self._memory = histogram.empty(histogram.MEMORY)

    def add(self, sample: WorkloadSample) -> None:
        interval = sample.interval_s
        if interval <= 0:
            return
        cores = sample.cpu_s / interval
        self._covered_s += interval
        self._samples += 1
        self._cpu_s += sample.cpu_s
        self._read += sample.io_read_bytes
        self._write += sample.io_write_bytes
        self._started += sample.started
        self._processes_max = max(self._processes_max, sample.processes)
        self._memory_weighted += sample.memory_bytes * interval
        self._memory_max = max(self._memory_max, sample.memory_bytes)
        self._memory_min = (
            sample.memory_bytes
            if self._memory_min is None
            else min(self._memory_min, sample.memory_bytes)
        )
        self._memory_last = sample.memory_bytes
        if cores >= self._active_share:
            self._active_s += interval
        histogram.add(self._cores, histogram.CORES, cores, interval)
        histogram.add(self._memory, histogram.MEMORY, sample.memory_bytes, interval)

    def close(self) -> Bucket | None:
        """The finished bucket, or None if nothing was observed."""
        if self._memory_min is None:
            return None
        return Bucket(
            series=self._series,
            start=self._start,
            width_s=self._width_s,
            covered_s=self._covered_s,
            samples=self._samples,
            active_s=self._active_s,
            cpu_s=self._cpu_s,
            io_read_bytes=self._read,
            io_write_bytes=self._write,
            started=self._started,
            memory_min=self._memory_min,
            memory_max=self._memory_max,
            memory_mean=self._memory_weighted / self._covered_s,
            memory_last=self._memory_last,
            processes_max=self._processes_max,
            cores_hist=tuple(self._cores),
            memory_hist=tuple(self._memory),
            logical_cores=self._logical_cores,
            epoch=self._epoch,
        )


def roll_up(
    samples: Iterable[WorkloadSample],
    *,
    width_s: float,
    logical_cores: int,
    epoch: int = 0,
) -> list[Bucket]:
    """Group samples by workload and bucket, and return the finished buckets in time order."""
    open_buckets: dict[tuple[float, str], SeriesAccumulator] = {}
    for sample in samples:
        start = bucket_start(sample.taken_at - sample.interval_s / 2, width_s)
        accumulator = open_buckets.get((start, sample.workload))
        if accumulator is None:
            accumulator = SeriesAccumulator(
                series=sample.workload,
                start=start,
                width_s=width_s,
                logical_cores=logical_cores,
                epoch=epoch,
            )
            open_buckets[(start, sample.workload)] = accumulator
        accumulator.add(sample)
    closed = (open_buckets[key].close() for key in sorted(open_buckets))
    return [bucket for bucket in closed if bucket is not None]


def merge(buckets: Sequence[Bucket], *, start: float, width_s: float) -> Bucket:
    """Combine buckets of one series into one wider bucket. Sums stay sums."""
    if not buckets:
        raise ValueError("nothing to merge")
    if len({bucket.series for bucket in buckets}) != 1:
        raise ValueError("buckets of different series cannot be merged")
    ordered = sorted(buckets, key=lambda bucket: bucket.start)
    covered = sum(bucket.covered_s for bucket in ordered)
    cores = ordered[0].cores_hist
    memory = ordered[0].memory_hist
    for bucket in ordered[1:]:
        cores = histogram.merge(cores, bucket.cores_hist)
        memory = histogram.merge(memory, bucket.memory_hist)
    latest = ordered[-1]
    return Bucket(
        series=latest.series,
        start=start,
        width_s=width_s,
        covered_s=covered,
        samples=sum(bucket.samples for bucket in ordered),
        active_s=sum(bucket.active_s for bucket in ordered),
        cpu_s=sum(bucket.cpu_s for bucket in ordered),
        io_read_bytes=sum(bucket.io_read_bytes for bucket in ordered),
        io_write_bytes=sum(bucket.io_write_bytes for bucket in ordered),
        started=sum(bucket.started for bucket in ordered),
        memory_min=min(bucket.memory_min for bucket in ordered),
        memory_max=max(bucket.memory_max for bucket in ordered),
        memory_mean=sum(bucket.memory_mean * bucket.covered_s for bucket in ordered) / covered,
        memory_last=latest.memory_last,
        processes_max=max(bucket.processes_max for bucket in ordered),
        cores_hist=cores,
        memory_hist=memory,
        logical_cores=latest.logical_cores,
        epoch=latest.epoch,
    )


def cores_percentile(bucket: Bucket, q: float) -> float | None:
    return histogram.percentile(bucket.cores_hist, histogram.CORES, q)


def memory_percentile(bucket: Bucket, q: float) -> float | None:
    return histogram.percentile(bucket.memory_hist, histogram.MEMORY, q)


def well_covered(bucket: Bucket, minimum: float = 0.5) -> bool:
    """Whether enough of the bucket was observed for baselines and trends to use it."""
    return bucket.covered_s >= minimum * bucket.width_s

    """Choose which tier answers a question, and say so.

A window is answered from the finest tier that still holds its whole span:
raw samples if the window starts within raw retention, minute buckets if it
starts within minute retention, hourly buckets otherwise. If that would return
more points than a chart can use, the choice moves to a coarser tier, and then
to wider steps. Every answer carries the tier and resolution it came from, so
a chart can state them and never mixes tiers without saying so.
"""

from __future__ import annotations

import math

from submeter.core.models import Record, Tier

_WIDTH_S = {Tier.MINUTE: 60.0, Tier.HOUR: 3600.0}


class TierChoice(Record):
    tier: Tier
    step_s: float
    reason: str


def choose_tier(
    *,
    start: float,
    end: float,
    now: float,
    raw_retention_s: float,
    minute_retention_s: float,
    raw_interval_s: float = 1.0,
    max_points: int = 2000,
) -> TierChoice:
    if end <= start:
        raise ValueError("the window must end after it starts")
    span, age = end - start, now - start
    widths = {Tier.RAW: raw_interval_s, **_WIDTH_S}
    if age <= raw_retention_s:
        tiers, reason = [Tier.RAW, Tier.MINUTE, Tier.HOUR], "window is inside raw retention"
    elif age <= minute_retention_s:
        tiers, reason = [Tier.MINUTE, Tier.HOUR], "window starts before raw retention"
    else:
        tiers, reason = [Tier.HOUR], "window starts before minute retention"
    for tier in tiers:
        if span / widths[tier] <= max_points:
            if tier is not tiers[0]:
                reason += f"; {tiers[0].value} would exceed {max_points} points"
            return TierChoice(tier=tier, step_s=widths[tier], reason=reason)
    coarsest = tiers[-1]
    step = widths[coarsest] * math.ceil(span / widths[coarsest] / max_points)
    reason += f"; {coarsest.value} buckets merged to stay under {max_points} points"
    return TierChoice(tier=coarsest, step_s=step, reason=reason)

    """The arithmetic behind leak detection and the usual range.

A leak is sustained growth with no plateau. The slope comes from the Theil-Sen
estimator, the median of the slopes between pairs of points, which one spike
cannot move. Growth that levels off is a cache warming up and is cleared.

The usual range is the median plus or minus a number of spreads, where spread
is the median absolute deviation scaled to match a standard deviation. Both
tolerate outliers, so one bad day does not widen the range.

These functions take plain numbers. The detectors that call them decide which
tier the numbers come from: minute buckets for the hourly check, daily
minimums of hourly buckets for the slow one.
"""

from __future__ import annotations

from collections.abc import Sequence
from statistics import median

from submeter.core.models import Record

_MAD_TO_SIGMA = 1.4826


def theil_sen(xs: Sequence[float], ys: Sequence[float], *, max_points: int = 300) -> float:
    """Median slope between all pairs of points. Thinned evenly above max_points."""
    if len(xs) != len(ys):
        raise ValueError("xs and ys must be the same length")
    if len(xs) > max_points:
        stride = len(xs) / max_points
        picks = [int(i * stride) for i in range(max_points)]
        xs, ys = [xs[i] for i in picks], [ys[i] for i in picks]
    slopes = [
        (ys[j] - ys[i]) / (xs[j] - xs[i])
        for i in range(len(xs))
        for j in range(i + 1, len(xs))
        if xs[j] != xs[i]
    ]
    if not slopes:
        raise ValueError("at least two points at different times are needed")
    return median(slopes)


def plateaued(
    xs: Sequence[float], ys: Sequence[float], *, tail: float = 1 / 3, ratio: float = 0.25
) -> bool:
    """True when the last part of the series grows far more slowly than the whole."""
    cut = int(len(xs) * (1 - tail))
    if len(xs) - cut < 3:
        return False
    overall = theil_sen(xs, ys)
    return overall <= 0 or theil_sen(xs[cut:], ys[cut:]) < ratio * overall


class GrowthResult(Record):
    flagged: bool
    slope_per_s: float
    duration_s: float
    reason: str


def check_growth(
    xs: Sequence[float],
    ys: Sequence[float],
    *,
    min_duration_s: float,
    min_slope_per_s: float,
    min_points: int = 8,
) -> GrowthResult:
    """Decide whether a series is a leak: long enough, steep enough, and still climbing."""
    duration = xs[-1] - xs[0] if xs else 0.0
    if len(xs) < min_points or duration < min_duration_s:
        return GrowthResult(
            flagged=False, slope_per_s=0.0, duration_s=duration, reason="not enough data yet"
        )
    slope = theil_sen(xs, ys)
    if slope < min_slope_per_s:
        reason, flagged = "growth is below the threshold", False
    elif plateaued(xs, ys):
        reason, flagged = "growth has levelled off", False
    else:
        reason, flagged = "sustained growth with no plateau", True
    return GrowthResult(flagged=flagged, slope_per_s=slope, duration_s=duration, reason=reason)


def usual_range(
    values: Sequence[float],
    *,
    sensitivity: float = 4.0,
    floor: float = 0.0,
    min_values: int = 5,
) -> tuple[float, float, float] | None:
    """Return (low, middle, high), or None while there are too few values to say."""
    if len(values) < min_values:
        return None
    middle = median(values)
    spread = max(floor, _MAD_TO_SIGMA * median(abs(value - middle) for value in values))
    return middle - sensitivity * spread, middle, middle + sensitivity * spread


def daily_minimums(
    times: Sequence[float], values: Sequence[float], *, utc_offset_s: float = 0.0
) -> list[tuple[float, float]]:
    """The lowest value of each local day, as (start of day, minimum), in time order."""
    lows: dict[float, float] = {}
    for moment, value in zip(times, values, strict=True):
        day = ((moment + utc_offset_s) // 86400) * 86400 - utc_offset_s
        lows[day] = min(value, lows.get(day, value))
    return sorted(lows.items())

def test_the_windows_lock_makes_the_calls_windows_expects(
    tmp_path: Path, monkeypatch: pytest.MonkeyPatch
) -> None:
    """A stand-in for msvcrt: this checks the calls, not how Windows answers them."""
    calls: list[tuple[int, int, int]] = []
    held: set[int] = set()

    def locking(fd: int, mode: int, nbytes: int) -> None:
        inode = os.fstat(fd).st_ino
        calls.append((mode, nbytes, os.lseek(fd, 0, os.SEEK_CUR)))
        if mode == 2:  # LK_NBLCK: fail at once if any other handle holds the byte
            if inode in held:
                raise PermissionError(13, "Permission denied")
            held.add(inode)
        else:
            held.discard(inode)

    fake = types.ModuleType("msvcrt")
    fake.LK_NBLCK, fake.LK_UNLCK, fake.locking = 2, 0, locking  # type: ignore[attr-defined]
    monkeypatch.setitem(sys.modules, "msvcrt", fake)
    monkeypatch.setattr(sys, "platform", "win32")
    path = tmp_path / "collector.lock"
    first, second = InstanceLock(path), InstanceLock(path)
    assert first.acquire() and not second.acquire()
    assert first.holder() == os.getpid() and path.read_bytes() == b""
    first.release()
    assert second.acquire()
    second.release()
    # every call is on one byte at offset 0: try, try and fail, unlock, try, unlock
    assert calls == [(2, 1, 0), (2, 1, 0), (0, 1, 0), (2, 1, 0), (0, 1, 0)]

def imports_of(path: Path) -> set[str]:
    tree = ast.parse(path.read_text(encoding="utf-8"))
    found = {
        node.module for node in ast.walk(tree) if isinstance(node, ast.ImportFrom) and node.module
    }
    found |= {
        alias.name
        for node in ast.walk(tree)
        if isinstance(node, ast.Import)
        for alias in node.names
    }
    return {name for name in found if name.startswith("submeter.")}


def test_no_module_imports_from_a_higher_layer() -> None:
    for path in SOURCE.rglob("*.py"):
        package = path.relative_to(SOURCE).parts[0].removesuffix(".py")
        if package == "__init__":
            continue
        for imported in imports_of(path):
            target = imported.split(".")[1]
            same_package = target == package
            assert same_package or LAYER[target] < LAYER[package], f"{path.name} imports {imported}"

    Design review log
    
  
    The design has been read three times as if by someone trying to prove its numbers wrong. The first pass found 14 flaws, the second 8, and the third, an audit of storage and time periods, 15. Thirty-four are fixed in the design and the prompt. Three cannot be fixed in version 1 and are listed under Known limits. Figures marked as estimates are reasoned, not measured, and the early phases exist to replace them with measurements.
    

  
    First pass, critical: the numbers would be wrong
    
  
    
    
    Polling cannot see short-lived children
    R01
    
      
    Agents spawn thousands of sub-second processes: git, ripgrep, test runners. A 1-second poll never sees most of them, so the workload you most want measured is the one most undercounted. The old gate, "50 short-lived children fully charged", was not achievable.
    
      
    FixTagged workloads run inside a Windows Job Object or a Linux cgroup. The kernel keeps exact totals for every process that ever lived in the group. Polling remains for rule-matched workloads and is labelled as such.
    
    
    The overhead budget and the sampling rate conflict
    R02
    
      
    Reading 300 processes one at a time every second in Python likely costs 3 to 6% of a core on Windows (estimate), against a 1% budget. USS is worse, since its cost grows with each process's memory.
    
      
    FixOne bulk system call returns every process's counters at once. Processes are split into a hot set at 1 s and a cold set at 10 s. USS is read slowly and only for the largest processes. The budget is now 1% at idle and 3% when active, and cadence yields before the budget does.
    
    
    Raw storage would reach several gigabytes
    R03
    
      
    300 processes at 1 s for 48 hours is 51.8 million rows before indexes. The first draft set retention by age only, with no ceiling on disk.
    
      
    FixWorkload totals are stored at full resolution. Per-process rows are written only when a value changes beyond a threshold. A disk budget, 2 GB by default, is enforced by trimming the oldest raw data first.
    
    
    Command lines leak secrets, and localhost is not private
    R04
    
      
    Command lines often carry API keys and tokens. The draft stored them in plain text and served them from an open local port, which any web page in your browser can reach. The planned MCP server would have handed them to agents.
    
      
    FixCommand lines are redacted before they are written. The API needs a token and checks Host and Origin headers. The MCP server never returns command lines.
    
    
    WSL2 and Docker Desktop show up as one process
    R05
    
      
    On Windows, everything inside WSL2 or Docker Desktop appears as a single VM process. If agents run there, attribution collapses into one opaque block.
    
      
    FixThe VM is shown as its own workload, labelled opaque. The ingest API accepts a second collector, so the Linux build can run inside WSL and report to the host. That collector is phase 7.
    
  
    

  
    First pass, high: misleading under real conditions
    
  
    
    
    Leak detection would go blind under memory pressure
    R06
    
      
    Windows trims working sets when memory is tight, so USS falls for a leaking process at the moment the leak matters.
    
      
    FixLeak detection uses private bytes on Windows and RSS plus swap on Linux. USS is kept for summing workloads.
    
    
    Workload totals would not add up to the system total
    R07
    
      
    Kernel time, interrupts and processes the daemon cannot read all fall outside per-process sums. A dashboard whose parts do not reach the whole invites distrust.
    
      
    FixSystem and Restricted are explicit buckets. Attributed, unattributed, system, restricted and idle must sum to 100% within 2%, and a test enforces it.
    
    
    Sleep and variable cadence create false spikes
    R08
    
      
    A laptop that sleeps for an hour would show one giant sample on wake. Mixed 1 s and 5 s samples also bias simple averages.
    
      
    FixProviders return cumulative counters. Rates come from deltas over a monotonic clock, gaps are recorded as gaps, and rollups are time-weighted.
    
    
    Two attribution rules were unreliable
    R09
    
      
    Matching on an environment tag means reading another process's memory, which fails for elevated processes. Parent IDs on Windows can point at an unrelated process after reuse.
    
      
    FixThe environment rule is gone. Group membership replaces it. A parent link counts only if the parent started before the child.
    
    
    Several acceptance gates could not be verified
    R10
    
      
    Task Manager has changed how it measures CPU between Windows builds, so it is no reference. A coding agent cannot run a 24-hour soak, and it builds on one OS.
    
      
    FixReference figures come from kernel counters. CI runs on Windows and Linux with a 30-minute soak. The 24-hour soak is yours to run. Hardware providers are tested from recorded fixtures.
    
  
    

  
    First pass, medium: noise and overconfidence
    
  
    
    
    Detectors would fire on normal behaviour
    R11
    
      
    A slope test flags any cache warming up. A baseline built from idle hours has near-zero spread, so all activity looks anomalous.
    
      
    FixA leak needs sustained growth with no plateau. Baselines are kept separately for idle and active states, with a learning period before any anomaly is raised.
    
    
    The bottleneck verdict claimed too much
    R12
    
      
    The classifier always returned an answer. On Windows, hard faults include harmless file mapping.
    
      
    FixEvery verdict carries a confidence level, and Inconclusive is a valid result. Windows memory pressure is read from commit and page writes.
    
    
    Hourly p95 could not be built from 1-minute p95
    R13
    
      
    A percentile of percentiles is not a percentile.
    
      
    FixHourly rollups are computed from raw samples while those still exist.
    
    
    GPU and Windows counters have traps
    R14
    
      
    GPU engine percentages do not add across engine types. Windows counter names change with the display language.
    
      
    FixGPU load is reported per engine type, with the busiest engine as the headline. Counters are opened by their English names.
    
  
    

  
    Second pass, fixed: gaps in the version 3 additions
    
  
    
    
    A tagged group's totals vanish with the group
    R15
    
      
    A Job Object is destroyed once its last process has exited and its handles are closed. A cgroup is removed once it is empty. Either way the counters go with it, and the design never said who reads the final totals.
    
      
    FixThe launcher holds the group while the command runs and saves its totals when the command ends. Anything that outlives the command is held open by a detached helper until the group is empty. The collector re-attaches to live groups after a restart.
    
    
    Per-process VRAM on Windows cannot be trusted yet
    R16
    
      
    Microsoft documents a fault in which the GPU Process Memory counter appears to leak. NVML cannot supply the figure on desktop Windows either.
    
      
    FixPhase 0 compares the per-process sum with the adapter total. If they drift, the provider is marked partial and leak detection stays off per-process VRAM.
    
    
    The bulk snapshot relies on a call Microsoft may change
    R17
    
      
    The single system call that makes the overhead budget reachable is documented as subject to change.
    
      
    FixA psutil fallback, a provider status of partial while it is in use, and a CI test that fails if the snapshot stops parsing.
    
    
    The sample alert rule was a sentence to be parsed
    R18
    
      
    A rule written as text needs its own small language, its own parser and its own error messages.
    
      
    FixRules are structured fields, validated like every other setting.
    
    
    Nothing could produce the loads the gates call for
    R19
    
      
    The gates ask for 500 sub-second children, a controlled leak and a CPU burn. No component made them.
    
      
    FixA load generator ships with the tests.
    
    
    A long build would lose the brief between sessions
    R20
    
      
    The prompt was a single message, and a build of eight phases runs across many sessions.
    
      
    FixThe builder's first step is to save the brief and the standing rules in the repository.
    
  
    

  
    Second pass, accepted: limits version 1 will state
    
  
    
    
    Work done on a workload's behalf is charged elsewhere
    R21
    
      
    An agent that asks Docker, a shared language server or an open browser to do work is not charged for it.
    
      
    OutcomeProcess accounting cannot fix this. It is listed under Known limits and stated beside agent totals.
    
    
    A CPU-second is not a fixed amount of work
    R22
    
      
    Efficiency cores and reduced frequency do less with the same second, so equal CPU time is not equal work.
    
      
    OutcomeCPU time is reported as measured, with frequency beside it. Normalising is left for a later version.
    
  
    

  
    Third pass, critical: storage that would lose or distort data

    # Build Submeter: a per-workload PC performance monitor

## What this is and why

I run many AI coding agents and heavy desktop apps at the same time, and I can't tell which of them is costing me what. I want a monitor I trust enough to make decisions from. It has three jobs of equal weight, all served from one data set:

1. Attribution: what does each workload (an agent run, a browser, an IDE, a build) cost in CPU, memory, I/O and GPU?
2. Live diagnosis: why is the machine slow right now?
3. Trends: how does behaviour drift over days and weeks, and where are the leaks and regressions?

Build it as a long-running local service with a web dashboard and a CLI. Windows 11 is the first target. Linux must work from the same codebase, so put everything OS-specific behind provider interfaces from the first commit.

Version 1 only observes. It must never change a process's priority or affinity, suspend it, or kill it. Placing a process tree that Submeter itself launches into a Job Object or cgroup for accounting is allowed. Setting any limit on that group is not. A control layer will come later, so shape analysis output as plain data objects a future policy engine could consume.

## Priorities

When goals conflict, resolve them in this order:

1. Never show a wrong number. When a metric is unavailable, record it as unavailable. Never substitute zero or an estimate. Every figure shown to me should be traceable to how it was measured.
2. Stay inside the overhead budget.
3. Cover more metrics.
4. Add features.

## Stack and conventions

- Python 3.12 or newer for everything in version 1, managed with uv. Ruff for lint and format. mypy in strict mode. pytest with pytest-asyncio.
- Pydantic v2 for all config, sample, finding and API models, with extra="forbid" and frozen=True.
- SQLite in WAL mode. FastAPI for the local API, with a WebSocket for live data. Typer for the CLI.
- Dashboard: a static front end served by the server process, with no Node toolchain needed to run it. Use a canvas chart library such as uPlot.
- psutil is the fallback and the cross-check, not the hot path.
- Store timestamps in UTC. Measure intervals on a monotonic clock.
- Before using any OS API you are not certain about, check current documentation instead of relying on memory. This applies most to Job Objects, cgroup v2 delegation, Windows performance counters, NVML, and psutil, whose API has changed across major versions.

## Architecture

Five layers with data flowing one way: providers, sampler, attribution, store, analysis. The API, CLI and dashboard are thin readers over store and analysis. Each layer must be testable in isolation from recorded fixtures.

### Three programs, one contract

Three programs share nothing but files on disk, and each writes only its own:

- submeter-collector: providers, sampler, attribution, redaction. It writes the raw files and nothing else.
- submeter-server: rollups, retention, analysis, alerts, API, dashboard, MCP. It writes the minute files and the history file, and reads the raw files.
- the launcher, `submeter run`: starts a tagged process tree and writes one small run file for it.

None of the three imports another, and every file has exactly one writer. The reason is that the collector is the hot path, and I want to be able to replace it with a Rust binary later without touching anything else. In phase 0, measure one full sample. If it takes more than 10 ms at 300 processes, or the collector holds more than 80 MB, stop and tell me, because that is my trigger for the Rust collector.

### Collection: two accounting paths

Agents spawn thousands of processes that live for less than a second, and polling cannot see them. If children live 300 ms on average, a 1-second poll captures under a third of their CPU time. So use two paths, and label every workload with the one that measured it.

Kernel accounting, for tagged workloads. `submeter run --as NAME [--label LABEL] -- COMMAND` launches the command inside a named Windows Job Object (nested jobs) or a Linux cgroup v2, and records the group in a run file. NAME is a stable workload name that is reused across runs, such as agent:refactor. LABEL identifies one run. Time series are kept per name and totals per run, so a new label never starts a new series. Warn in `doctor` when there are more than 200 distinct workload names. The kernel's totals for the group are authoritative: CPU time, memory, I/O and process counts, including processes that have already exited.

A group's counters disappear when the group does, so:

- The launcher holds the group open while the command runs, passes the command's exit code through, and writes the group's totals to its run file when the command ends. A tagged run is therefore accounted for even if the collector was not running.
- `submeter run` must return when the command returns, even if the command left background processes behind. Those processes stay in the group, so something has to keep the group open until it is empty and then save the final totals: a small detached holder, or the collector. Choose one and test it.
- The collector finds live groups from the run files and reads their totals each tick. After a restart it re-attaches to every live group.
- Set no limits on the group. Do not allow breakaway and do not set kill-on-close.

Bulk polling, for everything else. Do not walk processes one at a time on the hot path. On Windows, take one system-wide process snapshot per tick that returns CPU times, memory counters, I/O counters, thread and handle counts for every process. Microsoft documents that call as subject to change, so fall back to psutil if it fails, report the provider as partial while the fallback is in use, and keep a CI test that fails loudly if the snapshot stops parsing. On Linux, read /proc directly. Keep a hot set of recently active processes at the active interval and a cold set at the cold interval. Polled workloads are labelled as polled, with a note that short-lived children may be undercounted. On Linux, recover reaped children's CPU time from the parent's child-time counters.

Rules for both paths:

- Providers return cumulative counters. The sampler computes rates from deltas, so a change of cadence never loses or invents CPU time. Every sample records the interval it covers.
- Detect suspend and resume. Record a gap. Never emit one giant sample across it.
- Identify a process by pid plus start time. Treat a parent link as valid only if the parent started before the child.
- A process the collector cannot read is counted in a Restricted bucket with whatever is visible. It is never dropped.
- WSL2 and Docker Desktop appear on Windows as a single VM process. Show it as its own workload labelled opaque. Design the ingest path so a second collector running inside the guest can report to the host later (phase 7).

Memory: collect units that can be added across processes. Workload totals use USS (or PSS on Linux) so shared pages are not counted twice. USS is expensive, so read it on a slow cadence and only for the largest processes, and show the age of the reading. For growth and leak detection use private bytes on Windows and RSS plus swap on Linux, because Windows trims working sets under pressure and USS then falls for a process that is still leaking.

System-wide: per-core load and frequency, commit and available memory, paging split into reads and writes, disk latency, run queue, and PSI on Linux. A CPU-second is not a fixed amount of work, because efficiency cores and reduced frequency do less with it. Report CPU time as measured and show processor frequency beside it. Do not normalise workload figures in version 1.

Extended providers, each declaring its capability at the current privilege level (full, partial with what is missing, or unavailable with why):

- GPU load per process. On Windows use the GPU Engine counters. Engine percentages do not add across engine types, so report per engine type and use the busiest as the headline. Open counters by their English names so a localised Windows does not break them. On Linux use NVML and sysfs.
- VRAM per process. On Windows the GPU Process Memory counter is the only per-process source, because NVML reports the figure as unavailable under the desktop driver model. Microsoft documents a fault in which that counter over-reports. In phase 0, compare the sum of per-process values with the adapter total over time. If they drift, mark the provider partial and keep leak detection off per-process VRAM.
- Thermals and power. Temperatures through hwmon on Linux. Windows has no dependable unprivileged temperature source, so detect throttling from processor frequency and performance counters. Do not use psutil for frequency on Windows, where it reports only a nominal value. Battery on both.
- Network per process. Connection counts and remote endpoints per process, and bytes per interface. Per-process byte counts need administrator rights and are not part of version 1.

### Attribution

Every process maps to exactly one workload, in this order: kernel group membership, then rules, then inheritance from a valid parent, then Unattributed.

- Rules live in rules.toml and match on executable, command-line pattern, parent chain or working directory, with explicit priority. Do not match on environment variables, because reading another process's environment is unreliable.
- System (kernel, interrupts), Restricted, Unattributed and Submeter itself are always-visible workloads.
- Reconciliation invariant: for any window, attributed plus unattributed plus system plus restricted plus idle CPU time equals total capacity within 2%. Test it, and show it in the UI and in `submeter why`.

### Store

Data that expires together lives in a file together, so retention is always a file delete. Each file is SQLite in WAL mode with one writer.

- Raw files, one per UTC day, written by the collector: every sample at full resolution, the processes seen that day, and their redacted command lines stored once each. Kept 48 hours.
- Minute files, one per ISO week, written by the server: one bucket per minute for each workload and for the system. Kept 30 days.
- One history file, written by the server and kept: hourly buckets, hourly summaries per workload and executable, runs, sessions and their summaries, findings, epochs and baselines.
- Run files, one small JSON file per tagged run, written by the launcher with an atomic rename and read by the server.

Rules for raw files:

- Workload totals are written every sample. Per-process rows are written only when a value changes beyond a threshold, plus a full snapshot of every live process at the start of each file and every 10 minutes, so no query looks back further than that.
- A closed day's file is never written again and never migrated. Open closed files only for the length of a query, so they can be deleted on Windows.
- Process rows live only in raw files. Nothing keyed by pid is kept beyond 48 hours.

What every minute and hourly bucket records:

- for counters (CPU seconds, bytes read and written, processes started): the sum;
- for gauges (memory, process count, GPU load, frequency, run queue): minimum, maximum, time-weighted mean and last value;
- for CPU cores in use and for memory: a fixed-bin histogram that can be merged, so a percentile over any period comes from merged bins and never from averaging percentiles;
- covered seconds, sample count and active seconds, so a gap is never read as zero use;
- the capacity at the time (logical cores, memory) and an epoch id.

Build hourly buckets from raw data while it still exists. Rollups are idempotent: recomputing a bucket gives the same row. A bucket is final 30 seconds after it ends.

Summaries that must outlive the raw data:

- When a session stops or a tagged run ends, store its exact totals per workload: CPU seconds, peak and mean memory, I/O, processes started and top executables. `cost` and `diff` read these.
- Each hour, store the top 10 executables per workload by CPU time and by peak memory, keyed by executable name and never by pid. Keep these one year.

Epochs. An epoch is a stretch of time in which the sampling intervals, the rules file, each provider's status, the hardware and the Submeter version all stayed the same. Any change starts a new epoch with a stated reason. The collector records such events in the raw file and the server turns them into epochs. Never rewrite stored history when rules change.

Queries. Answer from the finest tier that covers the whole window, and return the tier and resolution with every result. Charts draw the minimum-to-maximum envelope. Leave buckets with less than half their time covered out of baselines and trends. Work out days and weeks in my time zone at query time, from buckets stored in UTC.

Operations:

- Put files in the platform's standard per-user locations for settings, data and state, with SUBMETER_HOME overriding all of them. `submeter store status` prints every file with its writer, size and coverage.
- One-instance lock per program. Rotating logs, 5 files of 5 MB each, with the same redaction as the store. The API token lives in a file only the current user can read.
- Durability: synchronous=NORMAL. A crash or power loss may lose up to 5 seconds of samples and must never corrupt a file. Keep read transactions short so the write-ahead log can be checkpointed, and truncate it at each checkpoint.
- At start, run an integrity check on the history file. Quarantine a damaged raw or minute file, record a gap and carry on.
- Back up the history file daily with SQLite's online backup and keep 3 copies. Migrate it only after a backup. Every file carries a schema version, and readers accept the current and previous versions.
- Enforce the disk budget, default 2 GB, across all files. When over budget, delete the oldest raw file first, never going below 24 hours, then backups down to one, then raise a finding. Never delete history automatically.
- Export to Parquet and JSON.

### Privacy and local security

Command lines often contain keys and tokens. Redact them before they are written: keep the executable and a pattern-scrubbed argument list, with a configurable redaction list and a strict mode that stores the executable only. Restrict every data file and the API token to the current user.

Binding to 127.0.0.1 is not enough, because any web page in my browser can reach a local port. Require a token on every HTTP and WebSocket request, reject requests whose Host is not a loopback name, and check Origin on the WebSocket. The MCP server must never return command lines or working directories. Nothing leaves the machine. Version 1 has no webhook, upload or update check. Both programs run as the signed-in user and never request administrator rights.

### Analysis

Detectors emit findings: type, severity, confidence, workload, time window, and the evidence that triggered them.

- Leak: sustained growth by a robust slope such as Theil-Sen, over a minimum duration, with no plateau. Growth that levels off is a warm-up and must be cleared. Track growth at workload level too, so a leak that spans short-lived processes is still seen. With default settings, growth of 50 MB an hour must be flagged within two hours. Run this check on the minute tier.
- Slow growth: on the hourly tier, fit the daily minimum of memory over at least 7 days. This catches leaks too slow for the check above.
- Baseline anomaly: keep baselines separately for idle and active states, using median and MAD with a floor on spread, computed from minute buckets over a trailing 14 days. Raise nothing until a learning period has enough samples. Hold the baseline still while an anomaly is open, so a regression does not become the new normal.
- Bottleneck verdict for a window: CPU-bound, memory-bound, I/O-bound, GPU-bound, thermally throttled or inconclusive. Always include a confidence level and the evidence. Inconclusive is a correct answer when signals disagree. On Windows judge memory pressure from commit and page writes, not from hard faults alone.
- Spike, swap storm, runaway process count.
- Session diff: compare two sessions or periods and rank what changed. Read the stored summaries, and flag any comparison of maxima or percentiles that crosses a change of sampling interval.

Each detector needs a fixture that triggers it and at least one quiet fixture that must not, including a cache warm-up for the leak detector.

## Configuration

Settings live in submeter.toml and attribution rules in rules.toml. Both load into frozen Pydantic models with unknown keys rejected. Precedence: command-line flag, environment variable, file, built-in default. Durations and sizes are written as strings such as "1s", "48h", "2GB".

Sampling settings and defaults:

- mode = adaptive (or fixed)
- active_interval = 1s (allowed 250ms to 10s)
- idle_interval = 5s (1s to 60s)
- cold_interval = 10s (5s to 60s)
- idle_after = 60s
- hot_cpu_threshold = 0.5%
- uss_interval = 30s, uss_top_n = 25
- gpu_interval = 2s, thermal_interval = 5s, network_interval = 5s
- on_battery_multiplier = 2
- overhead_limit: idle 1%, active 3%

Other settings: storage (retention for raw, minute and executables, disk_budget, change_threshold, keyframe_interval 10m, backups to keep), analysis (leak min_duration 2h and min_slope 50MB/h, slow_growth window 7d, baseline learning_period 7d, window 14d and sensitivity 4.0), verdict (window 5m, per-signal thresholds, min_confidence), alerts (rules, cooldown 15m, quiet_hours, channels dashboard and desktop), attribution (rules_file, inherit_from_parent, unattributed_alert, max_workload_names 200), privacy (redaction scrub or exe_only, extra patterns), providers (enabled list), api (port, mcp_enabled), ui (units, default_range), and named per-machine profiles that override any of the above.

Alert rules are structured fields: a workload pattern, a metric, above or below, a value, a duration and a severity. Do not invent a rule language to parse. An alert rule may name only these metric ids: cpu_cores, memory_bytes, processes and io_bytes_per_s for any workload, commit_fraction and throttled for the reserved workload `machine`, and overhead_fraction for the workload `submeter`. Refuse any other. Three rules ship built in: commit_fraction above 0.90 for 2 minutes (serious), throttled for 5 minutes (warning), and overhead_fraction above 0.03 for 5 minutes (warning).

Behaviour:

- Reject out-of-range values with the allowed range in the error. Never clamp silently.
- Hot reload on `submeter config reload` and on file change. Settings that need a restart must say so.
- `submeter config show --effective` prints every value with its source. `submeter config check FILE` validates without applying.
- Every effective change starts a new epoch and is marked on the charts, so a shift in the data can be traced to a settings change.
- A session may override the sampling interval for its own duration.
- The overhead guard outranks the configured interval. If the limit is exceeded, lengthen intervals and raise a finding.

Not configurable: observe-only behaviour, running without administrator rights, sending nothing off the machine, loopback binding, the token requirement, the rule that MCP never returns command lines, and the rule that unavailable metrics are never estimated.

## Known limits to show, not hide

Version 1 cannot measure some things. Say so in the dashboard and in `doctor`, beside the numbers they affect, instead of leaving a gap that looks like a zero:

- Work done for a workload by another process, such as the Docker daemon, a shared language server or a browser that was already open, is charged to that other process.
- Polled workloads on Windows undercount short-lived children.
- The WSL2 and Docker Desktop VM is opaque until the guest collector exists.
- Workload memory totals can lag by up to the USS interval.
- CPU time is not normalised for core type or frequency.
- Which files a process reads or writes is not recorded, only bytes and handle counts.
- Temperatures on Windows and per-process network bytes are not collected, because version 1 runs without administrator rights.

## Overhead budget

The monitor must not become the problem. With 300 processes running: under 1% of one core at idle cadence, under 3% at active cadence, and under 150 MB of memory across collector and server. If cadence and budget conflict, slow the cadence. Measure the cost of one full sample in phase 0 and tell me if these numbers are unrealistic before building on them.
