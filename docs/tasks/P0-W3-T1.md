## Provides

- On `SystemCounters`: per-core busy, idle, interrupt and DPC seconds; frequency and base frequency; commit used and limit; page reads and writes; disk queue length and latency; run queue; the on-battery flag; GPU load by engine type; adapter VRAM used and total.
- On `ProcessCounters`: handles; the System mark; the total-unit memory (USS or PSS) with its read time; GPU load by engine type (`docs/13-build-list.md:31`, `docs/17-build-prompt.md:111`).
- On `ProcessSample`: the same four (`sampler.py:91-105` builds it field by field, so P0-W4-T1 copies them across).
- On `SampleBatch`: per-core busy beside the existing machine total `cpu_busy_s: float`, which stays (C4); awake seconds; the count of capped deltas; the count of processes whose start time could not be read; a clock-step flag; the expected interval.
- On `WorkloadSample`: the gap flag (`bool`, default `False`); awake seconds; the total-unit memory with its age; GPU load by engine type; missing-member counts for I/O, memory and GPU load.
- On `Bucket`: awake seconds; the total-unit memory's max, mean and age; GPU load by engine type, max and mean.
- On `GroupTotals`: processes started and active; peak commit (R67).
- `Availability.OPAQUE`.
- No epoch on `WorkloadSample`; the raw `SCHEMA_VERSION` stays 1 (I9).
- A two-tier store in code: `Tier.RAW` and `Tier.HOUR`. The plan's word "hourly" describes the existing member `Tier.HOUR`, which keeps its name and value.

Every field above is optional and `None` by default, except the gap flag. Names and types: CQ-08.

- `AGENTS.md`: a setting outside its range is refused, never clamped: `storage.retention.minute` is refused as an unknown field.
