## Goal

A workload figure that none of its processes could read is unavailable (`None`, shown as n/a or `null`), never 0; one that only some could read is a partial sum with the count of members missing it; a tagged group that cannot report I/O reports it unavailable (R61). The total memory unit (USS on Windows, PSS on Linux) is a figure of its own with the time it was read. The last strict expected failure in the suite, R61's, passes and its marker is gone.
