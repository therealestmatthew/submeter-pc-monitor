## Work

1. `AlertRule.metric` and the applies-to check as under "Provides". The message for a refused rule names the rule and the allowed metrics or workloads.
2. `Verdict.thresholds` as a model; any other name is refused (`extra="forbid"` through `Record`).
3. The ranges. For each "not set yet" bound, use the value the owner recorded under B7 in `docs/STATUS.md`. If B7 is not recorded, stop and report `BLOCKED`.
4. Q15's default: `retention.executables` is unused in version 1. Mark it so in `docs/08-configuration.md`, as I57 does for the other unused settings, and give it no range; its bound in B7 is then not needed.
5. Every message for a refused value includes the allowed range (`docs/08-configuration.md:114`). Never clamp.
6. `uv run submeter config check examples/submeter.toml` must still exit 0 (`docs/PLAN.md` 4.2 row `examples/submeter.toml`).
