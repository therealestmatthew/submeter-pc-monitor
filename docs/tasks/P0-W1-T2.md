## Provides

- `scripts/probes/cpu_time_check.py`: per core, r1 = Δ(user + system + idle) ÷ elapsed and r2 = Δ(user + system + idle + interrupt + dpc) ÷ elapsed over 10 s, three repetitions; prints r1 and r2 for every core in every repetition, then the decision: r1 within 1.00 ± 0.01 on every core in every repetition: "subtract interrupt and DPC"; r2 within it: "keep the busy sum"; neither: "ask" (`docs/PLAN.md` 6.4, P0.4). Both: see CQ-02. Read by P0-O1 (`step1/cpu-time-check.txt`), which decides B4.
- `scripts/probes/restricted_share.py`: from a saved `top --json` list, the `restricted` row's `cpu_s` as a share of the summed `cpu_s` of all rows, and that row's `processes`. A list with no `restricted` row gives share 0 with 0 processes and says so in the output; it is not an error. Read by P0-O1 (`step1/restricted-share.txt`) for P0.5.
- `scripts/probes/replace_names.py <folder>`: replaces the current user name, host name, domain name and home folder in every file under the folder with `<user>`, `<host>`, `<domain>` and `<home>`, as whole tokens and case-insensitively, in UTF-8 and UTF-16 files, writing each file back in the encoding it was read in. Used by every owner task (`docs/PLAN.md` 3.1, Owner tasks) and by the test runner at every gate (6.2 step 3).
- `docs/review/ground-windows/step1-procedure.md`: every command of step 1, in order, with its output file name. Followed by the owner in P0-O1.

## Work

1. The three scripts run like `scripts/platform_check.py` (`uv run python scripts/probes/<name>.py`). Each keeps its logic in functions and runs only under `if __name__ == "__main__":`, imports nothing Windows-only at module level, and so can be loaded by path on Linux. They import nothing from `submeter` (each reads only files or psutil).
2. `cpu_time_check.py`: the ratios and the decision as under "Provides". The decision function takes the ratios of all three repetitions. On a system whose `cpu_times` has no `interrupt` or `dpc` field (Linux), `main()` says so and exits non-zero without measuring; the tests drive the functions directly.
3. `restricted_share.py`: reads the file named on its command line. The saved file may start with a line `$ <command>` and end with a line `exit=<code>` (P0-O1 saves every output that way), so the script reads the JSON between those lines when they are present, and the whole file when they are not.
4. `replace_names.py`: the function that does the replacement takes the folder and the names to replace as arguments, so the tests can plant made-up names; `main()` fills them from the current user (`getpass.getuser()`), host (`socket.gethostname()`, and its part before the first dot), domain (`USERDOMAIN`, where set) and home folder (`Path.home()`). The home folder is replaced before the user name, so `C:\Users\<name>\x` becomes `<home>\x`. A token boundary is any character that is not a letter, digit or underscore. UTF-16 is recognised by its byte-order mark; other files are tried as UTF-8. For a file that is neither, see CQ-03. It prints one line per file changed with the number of replacements, and never prints a name it replaced.
5. `step1-procedure.md`: in a PowerShell started normally (not "Run as administrator"), from a clone at the P0-W1 integration commit, in this order:
   1. `0-commit.txt` (`git rev-parse HEAD; git status --short`) and `0-integrity.txt` (`whoami /groups | Select-String "Mandatory Level"`, must read Medium Mandatory Level), as in `docs/PLAN.md` 6.2 step 4.
   2. The seven `AGENTS.md` commands, one file each, named as in 6.2 step 4 (`1-sync.txt` to `7-pytest.txt`).
   3. The time just before `scripts/platform_check.py`, then `platform-check.txt` (it must print `administrator or root: False`).
   4. `defender-asr.txt`: the Defender Operational log query for events 1121 and 1122 naming python.exe after that time (R126). If a standard user cannot read the log, the error is the file's content (Q4).
   5. `cpu-time-check.txt` (R125).
   6. `top-norules.json`: `submeter top --seconds 2 --json` with `SUBMETER_HOME` set to a new empty folder; then `restricted-share.txt` from it (R137).
   7. The suspend and clock checks of `docs/reference/windows-priorities.md` section 5 (R59, R124), one file each.
   8. `icacls` on the folders `platform_check.py` created, to see whether R100's private folders hold on Windows.
   9. The `AppData` and `Local AppData` values under `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders`, and whether `%APPDATA%\Submeter` or `%LOCALAPPDATA%\Submeter` lies under a OneDrive folder (`docs/reference/windows-priorities.md:77`, K18).
   10. `replace_names.py` over `docs/review/ground-windows/step1/`, then the name check of 6.2 step 4 (`git grep --cached -n -i -F -e $env:USERNAME -e $env:COMPUTERNAME -- docs/review/ground-windows/step1`, which must print nothing), then the commit on `owner/P0-O1` and the push, as 6.2 step 4 shows.

   Every file goes under `docs/review/ground-windows/step1/`, is written with `Out-File -Encoding utf8` (Windows PowerShell 5.1 writes UTF-16 with a bare `>`), starts with `$ <command>` and ends with `exit=<code>` (P0-O1; `docs/PLAN.md` 6.2, evidence layout). The five names P0-O1 lists are fixed: `cpu-time-check.txt`, `platform-check.txt`, `top-norules.json`, `restricted-share.txt`, `defender-asr.txt`. Other file names are the builder's choice. The procedure tells the owner to read every file before the commit.

## Questions for the lead

- `CQ-02`: If r1 and r2 are both within 1.00 ± 0.01 on every core (interrupt plus DPC time under 1% of elapsed), which decision does `cpu_time_check.py` print? The plan lists the r1 case first but does not say whether that order decides. Default: "ask", with the reason "interrupt plus DPC under 1% of elapsed: the check cannot tell", so the owner decides B4 as for "neither". If the answer is "r1 first", the test expects "subtract interrupt and DPC". The owner answers this question, not the lead, because the rule decides B4, a decision of `docs/PLAN.md` 5.6 (plan 4.3 item 6; `docs/STATUS.md` 7.3).
- `CQ-03`: What does `replace_names.py` do with a file that is neither UTF-8 nor UTF-16? The plan names only those two encodings. Default: leave it unchanged, print `not scanned: <path>`, and exit 1, so that the owner or the test runner sees it before the commit; the `git grep` name check then still runs. If the answer is "skip silently", that test changes to expect exit 0.
