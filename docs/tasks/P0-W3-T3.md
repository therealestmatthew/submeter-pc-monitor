## Provides

`tests/test_fixed_rules.py`: on every push, fails if
1. a call changes another process: the psutil methods `nice`, `ionice`, `cpu_affinity` or `rlimit` called with a value, or `suspend`, `resume`, `kill`, `terminate`, `send_signal` called at all; the Win32 names `SetPriorityClass`, `SetProcessAffinityMask`, `SuspendThread`, `NtSuspendProcess`, `TerminateProcess` named anywhere; `SetInformationJobObject` named anywhere except `src/submeter/providers/windows/job.py`;
2. `runas` or `requireAdministrator` appears anywhere in the package;
3. `src` imports `socket`, `http`, `urllib`, `ssl`, `ftplib` or `smtplib`;
4. `[project] dependencies` names anything but pydantic, psutil and typer;
5. a field of `Settings`, or of any model under it, turns on priority, affinity, suspend, kill, a memory cap, elevation, an upload, a webhook or telemetry (CQ-10).

A failure of this file stops the build at once (prompt section 2; `docs/PLAN.md` 6.11 item 5).

## Work

1. The checks are functions in the test file that take a root folder (or a model class), so each test runs one check on `src/submeter` and on a planted copy under `tmp_path`.
2. Process calls: a call whose function is an attribute or name `nice`, `ionice`, `cpu_affinity` or `rlimit` counts only with at least one argument (reading is allowed); the other five count with any arguments, `os.kill` included. A Win32 name counts as a bare name, an attribute or a string constant (so `getattr(kernel32, "TerminateProcess")` is caught).
3. Elevation: a case-insensitive whole-word match in the text of every file under `src/submeter`, not only `.py` files.
4. Network: `import x`, `import x.y` and `from x import y` where the top-level name is one of the six.
5. Nothing in `src` matches today (checked with grep on 22 November 2026, `docs/PLAN.md` 3.4). If a check fails on `src` at B, stop and report it: it is a fixed-rule finding for the owner, not something to change here.
6. No test in this file carries a mark or a skip (S1).
