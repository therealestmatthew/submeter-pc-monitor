## Tests first

These tests check behaviour that already exists, so they pass at B. This is a task that delivers only tests (`docs/PLAN.md` 7.2 step 4): the faults are the mutants. The reviewer runs `scripts/mutation_check.py` at B with the new tests and sees each targeted mutant fail them, and at the tip sees every R110 mutant caught.

| Behaviour (R110) | File | Mutant that must fail it |
| --- | --- | --- |
