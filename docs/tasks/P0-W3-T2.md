## Goal

A settings or rules file that the user names and that is missing, cannot be decoded as UTF-8 (a UTF-16 file included) or does not validate is refused: the command exits with code 2 and prints one line per problem (`docs/08-configuration.md:116`). A default file that is absent stays silent.

## Provides

One loader in `cli/_common.py` for every settings or rules file a user names (`--file`, `--rules`, and `config check FILE` under CQ-09's default). It refuses a named file that is missing, undecodable or invalid with exit code 2 and one line per problem on standard error, in the form `error: <problem>` that `_load` and `config check` already use at B.
