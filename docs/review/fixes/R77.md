# R77. On Linux other users' command lines are readable, and the baseline reads, matches rules on and stores them

**What changed.** `src/submeter/providers/psutil_provider.py`: on Linux, when a process's real uid differs from the collector's (`os.getuid()`), the provider does not read its command line, leaves `cmdline` None and marks the process restricted, as for any unread attribution input (decision 11, option (a); I17's assumption). The docs/10, docs/02 and docs/17 text, and the doctor hidepid report, are not part of this commit.

**Test.** `tests/test_collector.py::test_another_users_command_line_is_not_kept_on_linux`, with `sys.platform` patched to linux and `os.getuid` patched to 1000 (so it runs on any host): the process with real uid 1000 keeps its command line; the one with real uid 0 has `cmdline` None and `restricted` True. The `fake_process` stand-in gains a `uids()` read that defaults to the collector's own uid.
