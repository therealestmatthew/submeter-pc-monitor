# R100. Data folders and files are created 0755/0644, readable by other local users

**What changed.**
- `src/submeter/store/files.py` `ensure()`: each Submeter-owned folder (settings, data, state, raw, minute, backups, runs, logs) is made with mode 0o700 (on Windows, Python 3.13's `os.mkdir` turns 0o700 into an owner-only ACL), and on POSIX a folder that already exists is chmodded to 0o700. The minute folder stays in the list because R145's code moved to plan. The `InstanceLock` pid file is created 0o600 (`touch(0o600)`) before it is written, and the class docstring no longer says anyone may read it.
- `src/submeter/store/raw.py` `RawFile.__init__`: the day file is created 0o600 before `sqlite3.connect`; SQLite gives `-wal` and `-shm` the same mode. `Path.touch(0o600)` does the `os.open(path, O_CREAT|O_WRONLY, 0o600)` the finding asks for without adding an `import os` line, which lies outside G3's lines 67-71.
- `FileMap.readable_by_others()` lists every path under the settings, data and state folders that group or others can read, or returns `None` on Windows, where mode bits mean nothing. `src/submeter/cli.py` `doctor` prints it (`readable by others  none`, the paths, or `unavailable on Windows`) and adds `readable_by_others` to `--json`.
- The Python floor comes from R124 (`>=3.13`, I73). The token and backup files do not exist yet (R150, I71).

**Test.** `tests/test_files.py::test_submeter_files_are_private_to_the_user` (skipped on Windows): under umask 0o022, with `data/raw` made beforehand at 0755, `ensure()` leaves the folders at 0700, a new `RawFile`'s `.db` and the lock's pid file are 0600, `readable_by_others()` is empty, and after the pid file is chmodded 0644 it lists that file.
