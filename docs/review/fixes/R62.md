# R62: include_children is ORed with inherit_from_parent, so a rule cannot turn inheritance off

**What changed.** `src/submeter/attribution/rules.py`: `Rule.include_children` is `bool | None = None`. A matched rule's attribution is inheritable when `include_children` is set to true, not when it is set to false, and follows the Attributor's `inherit_from_parent` when it is omitted. This replaces `self._inherit or rule.include_children`, so the rule overrides the global setting in both directions (decision 8). The docs/08 and docs/14 sentences are the docs worker part.

**Test.** `tests/test_attribution.py::test_include_children_overrides_the_global_setting_both_ways`: three rules (`include_children` false, true, omitted), each with one child, under `inherit_from_parent` true and false. With the global setting on, the child of the `false` rule is unattributed; with it off, the child of the `true` rule still inherits; the child of the rule that omits it follows the global setting.
