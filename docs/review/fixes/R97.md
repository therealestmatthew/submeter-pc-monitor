# R97. exe_only keeps argv[0], which is a whole process title when a process rewrote it

**What changed.** `src/submeter/privacy/redact.py`: `redact_cmdline` takes the process's `exe`; in exe_only mode it returns `(exe,)` (or nothing when no executable name was read) and never `args[0]`. In scrub mode an `argv[0]` that holds spaces is split, its first word is kept as the program, and the other words are scrubbed like any argument. `src/submeter/store/raw.py`: `_register` passes `sample.exe`, inside R54's `_storable()`. `tests/test_baseline.py:193` passes `exe="claude"` for the new exe_only signature.

**Test.** `tests/test_privacy.py::test_exe_only_stores_the_executable_and_scrub_splits_a_title`: a `RawFile` in exe_only mode given cmdline `("postgres: alice appdb 10.0.0.5(5432) idle",)` and exe `postgres` writes no `alice` to the file; `redact_cmdline` returns `("postgres",)`; scrub hides the key inside `("worker --api-key sk-abcdefghijklmnopqrstu",)`.
