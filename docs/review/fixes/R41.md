# R41. On Windows the provider reads pid 0 (System Idle Process) as a process whose CPU is the machine's idle time

**What changed.** `src/submeter/providers/psutil_provider.py` `snapshot()`: on Windows pid 0 is skipped before it is read. `scripts/platform_check.py`: a new check, `check_reconciliation`, registered in `main()`, samples for 5 s with the real provider and sampler and fails when the summed per-process CPU exceeds machine busy time by more than 5%. It does not skip processes whose CPU is None, because R57, which makes CPU optional, moved to plan. R125's interrupt and DPC subtraction waits for its own Windows check (I14). The docs/17 and windows-priorities text is the docs worker's.

**Test.** `tests/test_collector.py::test_windows_idle_process_is_not_read`: with `sys.platform` patched to win32, `process_iter` yields a pid 0 'System Idle Process' stand-in and an ordinary one; `snapshot()` returns only the ordinary one.
