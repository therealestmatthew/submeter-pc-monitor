# R45: the baseline 'reconciliation' test checks only conservation

**What changed.** Tests only. `tests/test_baseline.py`: `test_attribution_order_inheritance_and_reconciliation` is renamed `..._and_conservation`, because it checks only that workload sums equal process sums (for polled workloads, after R61). `tests/test_attribution.py` gains a reconcile check built from `SampleBatch.cpu_busy_s`, `interval_s` and `logical_cores`: capacity is `interval_s * logical_cores`, Idle is capacity minus busy, the workload totals are the reported totals (the group's totals for the tagged workload, R61), System is 0 because the baseline assigns nothing to it, and 'not seen by polling' is busy minus the workload totals minus System (I20). Applied after R61 (I23). The reconciliation code itself is the task R119(b) moves to the new P2 (I11).

**Test.** `tests/test_attribution.py::test_capacity_reconciles_with_a_not_seen_by_polling_term`: 4 cores over 1 s, busy 1.5 CPU-s, a rule-matched shell at 0.2, a tagged process polled at 0.3 whose group reports 0.6, and an idle unattributed process. Capacity, Idle (2.5), the workload totals (0.8), System (0) and 'not seen by polling' (0.7) are each non-negative and sum to capacity.
