# R127. Windows private bytes come from psutil's 'private' alias with a silent getattr fallback to working set

**What changed.** `src/submeter/providers/psutil_provider.py`: memory is `memory_info().vms` on Windows (PagefileUsage, which equals PrivateUsage) and `.rss` elsewhere, with no `getattr` fallback. `scripts/platform_check.py` no longer reports the `private` attribute; it names the figure the provider reads.

**Test.** `tests/test_collector.py::test_windows_memory_is_private_bytes`: with `sys.platform` patched to win32, a stand-in whose `memory_info()` has rss 100, vms 300 and no `private` gives `memory_bytes` 300.

**Platform.** Linux (Python 3.14.5), with `sys.platform` patched to win32 for the test. Nothing here ran on Windows.
