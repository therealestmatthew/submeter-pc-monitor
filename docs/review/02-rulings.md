# Rulings on the stage 1 review

The owner's rulings on `01-adversarial-review.md`, recorded as step 1 of "After my rulings" in `prompts/01-execution-prompt.md`.

## The ruling

On 21 November 2026 the owner answered the stage 1 stop with: **"Accept all."** That accepts every recommendation in the report: each finding's recommended disposition, and, for each of the 42 findings that needed a decision, the recommended option. No reasons were given, so the reason column below is empty except where a ruling had to be read together with another (see **How the rulings combine**).

What a disposition means here:

- `fix now`: the document change is made now, one commit per finding, and the change to the baseline code is made now, test first, unless it grows past about fifty changed lines, in which case it moves to the plan (see **Code changes moved to the plan**).
- `plan`: the document change is made now, so that nobody builds from a document known to be wrong; the work itself is a task in `docs/PLAN.md`.
- `defer`: for the scope findings R140 to R152 the feature itself leaves version 1. The documents now say so, and keep its corrected design as the starting point for later.
