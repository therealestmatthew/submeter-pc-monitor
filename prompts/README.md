# Prompts

One prompt starts each kind of session. Start a session in the repository root and say: "Read prompts/NAME and follow it."

| File | Starts | Written by |
| --- | --- | --- |
| `01-execution-prompt.md` | The first session: an adversarial review, a stop for rulings, a formal plan, then the orchestration prompt | Part of the package |
| `02-orchestration-prompt.md` | The build: a lead session and a parallel swarm of builders and reviewers | The first session, at its stage 3 |

`docs/17-build-prompt.md` is a third prompt, kept as the specification in compact form. It can start a single-session build on its own, but in this package the two prompts above replace its working instructions.
